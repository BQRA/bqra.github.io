Installation controls & test guide

Try the experience

  1. Open this page in Safari. Tap “Enable audio & microphone” and allow microphone access.
  2. Press the pedal (keyboard B): handset down, idle. Release B: handset lifted, dial tone.
  3. Tap “Call Yesterday for Tomorrow”: redial beeps → two rings → pickup → microphone recording.
  4. Press the pedal to stop and reset, or tap “Stop recording”. Download the latest message below the status.

Simulation uses the same handset actions. Held/repeated B keydowns are ignored. Returning the handset cancels the entire call sequence immediately.

iPad Safari setup

For reliable microphone permission, serve this unchanged HTML file from an HTTPS address and open that address directly in Safari. An insecure HTTP address on another device will not work for microphone recording. An iPad Files / Quick Look preview may block microphone access; open the HTTPS page in Safari instead.

Sound activation requires a tap. If Safari interrupts audio after locking the screen or switching apps, lift the handset and tap “Enable / recheck permissions”. Keep Safari in the foreground. Hiding the page stops the call and microphone.

The microphone is checked during setup and opened again before dialing; recording starts only after the pickup sound finishes. Safari may ask for permission again. If the permission dialog stays open, answer it before retrying.

Maximum recording: 5 minutes. Hanging up also keeps the latest message available to download. Reset stops microphone tracks; old object URLs are released when replaced. Reloading clears recordings. Download format follows the browser (usually MP4/M4A or WebM).

Connect the USB handset before setup. Sound and microphone use the iPad’s selected devices; verify the actual handset route on the iPad. These are locally generated test tones, not a real telephone call.
